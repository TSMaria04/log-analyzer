# 🧩 Автоматический анализатор журналов и детектор угроз

CLI-инструмент на Python для автоматизированного анализа логов веб-сервера (Nginx/Apache). Проект позволяет выявлять следы веб-атак и аномальную активность с использованием регулярных выражений

---

## 🚀 Функционал

- 🔍 **Детектор популярных веб-атак:**
  - SQL-инъекции (`UNION SELECT`, `OR 1=1`)
  - XSS-атаки (`<script>`, `alert()`)
  - Path Traversal / LFI (`etc/passwd`, `../`)
- 🔑 **Обнаружение Brute-Force:** автоматический отслеживание порога неудачных попыток авторизации (HTTP 401)
- 📊 **Наглядный отчёт:** цветовая индикация сгруппированных инцидентов и подсвечивание проблемных IP

---

## 🛠 Технологический стек

* **Язык:** Python 3.12
* **Модули:** `re` (регулярные выражения), `collections` (`defaultdict`), `colorama`
